# Data Directory

All datasets are synthetic and deterministically generated (seed=42).
Regenerate everything from scratch:

```bash
python data/generate_all.py
```

## Datasets

### Drug Interaction Databases

| File | Records | Purpose |
|------|---------|---------|
| `drug_interactions_10k.json` | 10,000 | Full evaluation |
| `drug_interactions_200.json` | 200 | Quick testing / demo |

**Schema** (per record):
- `drug_id` — integer identifier
- `drug_a`, `drug_b` — drug names (generated from pharmacological prefix+suffix)
- `severity` — one of: `none`, `mild`, `moderate`, `severe`, `contraindicated`
- `mechanism` — pharmacological interaction mechanism
- `clinical_recommendation` — clinical guidance

**Severity distribution** (target): 40% none, 25% mild, 20% moderate, 10% severe, 5% contraindicated.

**Record size**: each record serializes to <= 256 bytes (compact JSON).  256 is a power-of-2 chosen for BFV slot alignment in the PIR scheme.

**Drug names**: 142 unique names generated by combining 50 real pharmacological prefixes (Ator-, Metfor-, Amoxi-, Lisi-, Omepra-, ...) with 30 real class suffixes (-statin, -pril, -olol, -mab, -zole, -mycin, ...).

### Patient Profiles

| File | Patients | Purpose |
|------|----------|---------|
| `synthetic_patients_1000.json` | 1,000 | Full evaluation (incl. 50 edge cases) |
| `synthetic_patients_10.json` | 10 | Quick testing / demo |

**Schema** (per patient):
- `patient_id` — string identifier (P0000..P0999)
- `age` — years, Normal(55, 15) clipped [18, 95]
- `bmi` — kg/m^2, Normal(27, 5) clipped [15, 50]
- `systolic_bp` — mmHg, Normal(130, 20) clipped [80, 220]
- `diastolic_bp` — mmHg, Normal(80, 12) clipped [50, 130]
- `cholesterol_total` — mg/dL, Normal(200, 40) clipped [100, 350]
- `cholesterol_hdl` — mg/dL, Normal(55, 15) clipped [20, 100]
- `glucose_fasting` — mg/dL, Normal(100, 25) clipped [60, 300]
- `num_medications` — integer [0, 12)
- `num_conditions` — integer [0, 8)
- `current_drugs` — list of 1-5 drug names from the drug pool

**Edge cases** (last 50 patients): very elderly with many comorbidities, young/obese with metabolic syndrome, hypertensive crisis, healthy minimum, hypoglycemic — with slight randomization.

## Loading Datasets

```python
from src.utils.data_utils import load_drug_db, load_patients

# Full evaluation
drugs = load_drug_db("10k")       # 10,000 records
patients = load_patients("1000")  # 1,000 patients

# Quick testing
drugs = load_drug_db("200")       # 200 records
patients = load_patients("10")    # 10 patients
```

## Note on Real Data

If using real clinical data (e.g., from MIMIC-III), ensure compliance with
data use agreements and do **not** commit real patient data to this repository.
